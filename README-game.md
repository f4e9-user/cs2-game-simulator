# CS2 电竞选手人生模拟器：游戏系统说明

这是一款以 CS2 职业生涯为主题的文字冒险 + 数值模拟游戏。它不是单纯的随机事件选择器，而是把选手成长、压力疲劳、战队合同、赛事资格、队友阵容、经济压力、名气舆论和 AI 叙事串在一起的职业生涯模拟。

玩家扮演一名想打职业的 CS2 新人，从路人阶段开始，通过训练、天梯、赚钱、休息、申请战队、参加赛事、经营队伍关系和处理随机事件，尝试一路进入职业队，并在有限的生涯时间内打出足够高的成就。

---

## 游戏目标

游戏没有单一线性胜利条件。它更像一段职业生涯：

- 短期目标：活下来，控制压力和疲劳，保证 AP 和经济不断档。
- 中期目标：提升能力，打出赛事成绩，加入更高等级战队。
- 长期目标：进入职业阶段，冲击 S 级赛事、Major、高名气和传奇结局。

玩家可能以多种方式收束生涯：

- 成为高名气职业明星。
- 赢下 Major 或重要赛事。
- 作为自由人打出草根传奇。
- 长期效力同一队成为忠诚老将。
- 因压力、伤病、经济或普通退役结束职业道路。

---

## 核心循环

一局游戏的主循环：

```text
抽特质 / 分配属性
      ↓
进入每周回合
      ↓
行动阶段：训练、天梯、恢复、赚钱、购物、报名、战队和队伍管理
      ↓
结束行动阶段，根据最新状态 pickup 本回合事件
      ↓
事件阶段：选择固定选项，或在 AI 启用时输入自由行动
      ↓
结算属性、压力、疲劳、手感、名气、资金、战队关系和赛事状态
      ↓
推进周数，刷新事件，检查晋级、薪资、贷款、资格和结局
```

每回合的关键资源是 AP。玩家不能无限训练，也不能无限恢复。高收益行动通常带来疲劳、压力或经济成本；恢复行动会牺牲手感或成长速度。

当前实现把回合拆成两个阶段：

- `action`：行动阶段。玩家可以做日常行动、购物、贷款、典当、申请/离队、报名/弃赛、队伍管理等操作。
- `event`：事件阶段。系统已经根据本回合行动后的最新状态选出事件，玩家只能处理事件选项或 AI 自由行动。

`currentEvent` 只在事件阶段存在；行动阶段不会提前固定下一事件。

### 长事件流程

普通事件之外，游戏支持同回合 Event Sequence：

- 战队面试会连续走完多个提问后再结算。
- 家人危机、队内冲突会以多步流程展开。
- Bo3 / Bo5 赛事会按地图拆成同回合系列赛。
- 赛事上下文会围绕报名、赛前、赛后承接，但比赛周只出比赛事件。

事件卡会显示当前流程进度，历史记录也会把同一流程的记录分组显示。

## 开局系统

### 特质

开局会随机抽取 3 个特质，玩家可以重抽 1 次。特质同时影响：

- 属性底线或修正。
- 标签和叙事身份。
- 行动检定、事件门槛、团队协同和部分风险。

典型特质方向：

- 枪法天才：提高敏捷，带来 `aimer` / `mechanical` 标签。
- 战术大脑：提高智力，带来 `igl` / `tactical` 标签。
- 冰冷心脏：提高心态，擅长抗压。
- 训练狂：成长潜力强，但可能更难停下来恢复。
- 玻璃腕：枪法强，但伤病风险高。
- 自负、急性子、社恐、沉迷型等负面或混合特质，会在事件和团队系统里持续产生影响。

特质不是简单的正负数值。同一个行动在不同角色身上会呈现不同风险，例如 `grinder` 更适合训练，`solo` 更适合天梯但可能伤害团队协同。

### 开局身份

本版本开局身份固定为「无标签新人」。玩家不是从一组选定背景中开局，而是通过特质、属性分配和后续选择逐步塑造职业身份。

开局重点是：

- 选手名。
- 随机 3 个特质。
- 在五个竞技属性上分配 12 点。

## 生涯阶段

正式阶段链路：

```text
rookie -> youth -> second -> pro -> retired
```

对应含义：

- `rookie`：路人新人，还没有真正进入体系。
- `youth`：青训，开始接触俱乐部体系。
- `second`：二线队，具备半职业或次级赛事资格。
- `pro`：职业队，进入高等级赛事生态。
- `retired`：退役。

阶段不是只靠经验自动升级，而是和战队、赛事成绩和晋级叙事事件绑定。

### rookie -> youth

新人进入青训的核心路径是加入青训档战队。申请青训前通常需要证明自己：

- C/B 级赛事累计参赛不少于 3 场。
- 其中至少参加过 1 场 B 级赛事。
- C/B 级赛事至少夺冠 1 次。
- 或者拥有枪法天才相关天赋路径。

申请会消耗 AP，并进入等待回应或面试链路。面试成功后会生成战队 Offer，接受后进入 `youth`。

### youth -> second

青训晋级二线队依赖 B 级赛事门槛：

- B 级赛事参赛不少于 3 场。
- B 级赛事夺冠不少于 1 次。

满足条件后，系统会注入晋级叙事事件，而不是直接静默升级。晋级成功代表签下更高层级合同，会同步换到真实二线俱乐部，并重新生成队友阵容、月薪和队伍信任。

### second -> pro

二线队晋级职业队依赖 A 级赛事门槛：

- A 级赛事参赛不少于 3 场。
- A 级赛事夺冠不少于 1 次。

满足条件后同样通过晋级签约事件推进。晋级成功会换到真实职业俱乐部。

`pro` 是当前正式竞技阶段终点。更高的明星、传奇、老将是目标和结局评价，而不是新的阶段。

## 属性系统

玩家有五个可分配竞技属性，另有一个经济属性 `money`。

| 属性 | 含义 | 主要影响 |
| --- | --- | --- |
| `intelligence` 智力 | 战术理解、复盘、决策 | 系统训练、陪玩指导、比赛 rating、部分事件选择 |
| `agility` 敏捷 | 枪法、反应、定位 | 天梯、比赛胜率、击杀、爆头率 |
| `experience` 经验 | 比赛经验和稳定输出 | 枪法基础、决策基础、长期表现 |
| `mentality` 心态 | 抗压和情绪稳定 | 压力增量、比赛稳定性、恢复行动 |
| `constitution` 体能 | 身体耐受和恢复能力 | 疲劳增量、伤病风险、连续作战 |
| `money` 资金 | 经济资源 | 商店、贷款、工资、奖金、罚款和生活压力 |

开局可在特质底线之上分配 `12` 点，但只能分配到五个竞技属性：

- `intelligence`
- `agility`
- `experience`
- `mentality`
- `constitution`

`money` 不参与开局分配。它通过赛事奖金、工资、赚钱行动、贷款、朋友借款、典当、商店消费和罚款变化。

竞技属性通常在 `0-20` 区间，资金上限更高。

### 成长衰减

成长不是线性堆数值。属性越高，继续成长越慢：

| 当前属性 | 成长倍率 |
| --- | --- |
| `< 5` | `1.0` |
| `< 10` | `0.7` |
| `< 15` | `0.4` |
| `>= 15` | `0.15` |

生涯总成长有上限，当前核心成长预算为 `30`，只作用于五个竞技属性；`money` 不计入成长预算。这意味着玩家必须选择成长方向，而不是全属性拉满。

## 状态系统

除核心属性外，游戏还维护一组高频波动状态。

### AP

`actionPoints` 是每回合行动资源。日常行动、申请战队、队伍管理等会消耗 AP。AP 决定玩家每周能做多少事。

### 压力 stress

压力范围是 `0-100`。压力过高不是立刻结束，而是进入挂满计数：

- 压力达到上限后累计 `stressMaxRounds`。
- 连续撑满到阈值后触发 `stress_breakdown` 结局。
- 心态越高，每回合被动降压越明显。
- 疲劳超过 70 时，正向压力增量会被放大。

正向压力增量的核心逻辑：

```text
最终压力增量 =
  基础压力增量
  × 心态倍率
  × 特质压力倍率
  × Buff 压力倍率
  × 高疲劳压力放大
```

当前心态倍率：

| 心态 | 正向压力倍率 |
| --- | --- |
| `>= 16` | `0.30` |
| `>= 13` | `0.55` |
| `>= 9` | `0.85` |
| `>= 5` | `1.25` |
| `< 5` | `1.60` |

疲劳达到 `70` 后，正向压力增量还会额外放大到 `1.4` 倍。降压效果不会因为高心态被削弱。

### 疲劳 fatigue

疲劳范围是 `0-100`。训练、天梯、比赛、赚钱行动会增加疲劳；休息、度假、商店服务会降低疲劳。

正向疲劳增量的核心逻辑：

```text
最终疲劳增量 =
  原始疲劳增量
  × 体能倍率
  × 特质疲劳倍率
  × Buff 疲劳倍率
```

当前体能倍率：

| 体能 | 正向疲劳倍率 |
| --- | --- |
| `>= 15` | `0.30` |
| `>= 11` | `0.55` |
| `>= 7` | `0.85` |
| `>= 4` | `1.35` |
| `< 4` | `1.60` |

为了避免高体能角色完全无成本行动，正向增量有最低值：日常行动最低 `5` 点疲劳，随机事件最低 `2` 点疲劳，正式比赛最低 `8` 点疲劳。

### 手感 feel

手感影响比赛即时发挥：

- 正手感提高有效枪法。
- 负手感降低比赛表现。
- 休息和断网会恢复身体，但可能让手感下降。
- 外设升级可以提高或改变手感上限。

默认手感范围是 `-3 ~ +3`，外设系统可以把上限推高。

### tilt

`tilt` 是心态波动，范围 `0-3`。失败、连败、爆冷输球会增加 tilt；逆转胜或恢复类内容可能降低 tilt。比赛中 tilt 会直接削弱有效枪法。

### 名气 fame

名气影响：

- 战队申请门槛。
- 高等级俱乐部门槛。
- 媒体、粉丝和社交事件。
- 部分赛事机会。
- 结局评价。

名气不是纯正收益。更高曝光也会带来媒体事件、压力和舆论风险。

## 日常行动

日常行动是玩家主动塑造角色的主要手段。当前行动包括：

| 行动 | AP | 主要收益 | 主要代价 |
| --- | ---: | --- | --- |
| 打天梯 | 30 | 敏捷成长、手感 | 疲劳、压力、tilt 风险 |
| 系统训练 | 30 | 智力成长 | 疲劳、压力 |
| 休息一天 | 30 | 降疲劳、降压力 | 手感下降 |
| 度假断网 | 50 | 大幅恢复 | 手感明显下降，占用大量 AP |
| 健身锻炼 | 30 | 体能成长 | 疲劳 |
| 冥想静心 | 15 | 降疲劳、降压力 | 恢复较轻，不提供成长 |
| 心理训练 | 30 | 心态成长 | 疲劳、压力 |
| 代练接单 | 35 | 赚钱，偏敏捷检定 | 高疲劳、高压力 |
| 陪玩指导 | 30 | 赚钱，偏智力检定 | 疲劳、耐心消耗 |
| 网吧打工 | 35 | 赚钱，偏体能检定 | 高疲劳 |

行动会走检定。检定通常由主属性、可选副属性、特质加成、特质惩罚和难度共同决定。

### 行动 Combo

日常行动支持同一回合内的行动连锁。玩家先执行一个行动，可能开启本回合 combo 标记；后续按正确顺序执行匹配行动时，会消费标记并获得额外收益。

当前 Combo 路线：

| 连锁 | 额外收益方向 |
| --- | --- |
| 系统训练 -> 打天梯 | 敏捷成长提高，tilt 风险降低 |
| 打天梯 -> 系统训练 | 智力成长提高，压力增长降低 |
| 冥想静心 -> 打天梯 / 心理训练 | 压力和 tilt 风险降低 |
| 健身锻炼 -> 系统训练 / 打天梯 | 疲劳增长降低 |
| 度假断网 -> 打天梯 | 找回手感，疲劳增长降低 |
| 代练接单 / 陪玩指导 / 网吧打工 -> 冥想静心 / 休息一天 | 额外恢复疲劳和压力 |

Combo 只在本回合有效，触发后消耗，回合结束会清空。它不同于商店 Buff：Buff 是持续收益，Combo 是行动顺序带来的一次性收益。

## 事件系统

事件系统负责制造职业生涯的不确定性。事件会根据玩家当前状态动态抽取。

事件来源包括：

- 训练
- 天梯
- 战队
- 试训
- 赛事
- 媒体
- 生活
- 救助
- 博彩
- 作弊
- 休养
- 压力
- 对手
- 直播 / 社交
- 每日链路
- 皮肤
- 经纪人
- 赛事上下文

事件筛选会考虑：

- 当前阶段。
- 玩家标签。
- 禁止标签。
- 最近事件去重。
- 压力、疲劳、名气和经济状态。
- 是否报名赛事。
- 是否处于面试或申请链路。
- 是否强制休养。
- 是否签约经纪人。

某些状态会强插事件。例如强制休养时优先进入休养事件池，报名赛事后会出现赛前或赛后上下文，申请战队后会进入回应/面试链路。

### 自由行动

开启 AI 后，玩家可以在事件阶段输入自定义行动。系统会让 LLM 评判行动质量，并映射成检定加成：

- `poor`：负面或低质量行动。
- `ok`：普通行动。
- `good`：较好行动。
- `excellent`：非常贴合情境的行动。

随后系统会二次校验这个判定是否合理。校验失败时会降级为普通选择，避免 LLM 给出过度奖励。自由行动最多 50 个字，只在事件阶段可用。

## 战队系统

战队是生涯推进的核心系统之一。它不仅提供身份，还影响赛事资格、薪资、队友、协同、积分榜和社交动态。

### 俱乐部等级

当前俱乐部分为：

- `youth`：青训队。
- `semi-pro`：半职业 / 二线队。
- `pro`：职业队。
- `top`：顶级队。

不同等级有不同阶段和名气门槛。顶级队通常要求职业阶段和较高名气。

### 申请和 Offer

玩家可以申请俱乐部。申请会：

- 消耗 AP。
- 检查阶段、名气、贷款违约禁转等门槛。
- 激活该俱乐部运行态。
- 生成等待回应。
- 后续通过事件进入面试或拒绝链路。

面试成功后会生成 Offer。接受 Offer 后：

- 进入对应最低阶段。
- 获得月薪。
- 生成队友阵容。
- 初始化队伍信任。
- 加入战队积分榜生态。

赛事晋级签约也复用同一套入队结算，但不会按违约跳槽处理；原队伍资格会清空，新队伍会重新建立阵容和薪资。

### 跳槽和合同争议

如果玩家已有战队又接受新 Offer，会触发违约式跳槽：

- 名气下降。
- 压力上升。
- 添加合同争议标签。
- 新队初始信任更低。

这让「骑驴找马」有收益，也有舆论和团队代价。

### 薪资和奖金分成

战队提供月薪，薪资按周期发放。更高等级队伍薪资更高，但赛事奖金分成给玩家的比例更低：

| 战队等级 | 玩家奖金分成 |
| --- | --- |
| youth | 85% |
| semi-pro | 70% |
| pro | 60% |
| top | 50% |

顶级队给稳定薪资和赛事资格，但选手不再拿走全部奖金。

## 阵容和队友

加入战队后会生成队友阵容。队友有：

- 角色：`IGL`、`AWPer`、`Entry`、`Support`、`Lurker`
- 个性：严格、支持、明星、苦练、戏剧型
- 数值：敏捷、智力、心态、经验
- 特质标签
- 成长空间
- 队友默契
- 可见队伍身份

队友不是纯展示文本，会影响比赛团队加成。

### 队伍管理

加入战队后，战队面板会开放队伍管理动作。这些动作消耗 AP，属于本回合行动的一部分。

- 队友加练：指定一名队友加练，按队友角色判定主要成长属性。成功会让该队友对应属性小幅成长，并提高默契。
- 战术会议：尝试统一默认战术。成功提高 `teamTrust`，并获得一次性赛事情境增益「战术统一」。
- 安抚更衣室：只在 `locker-tension` 或低 `teamTrust` 时可用。成功提高队伍信任并移除更衣室紧张。
- 挽留核心队友：在队友离队压力出现时尝试保住核心。
- 队伍训练重点：选择队伍训练方向，改变短期队伍培养和状态。

队伍管理不能在赛事实际比赛周进行，但报名后的备赛周仍可以安排。当前版本会让队伍管理影响队友属性、队友默契、队伍信任、疲劳、压力和短期比赛稳定性。

### 队友默契和队伍默契

每名队友有自己的队友默契。它表示玩家和这名队友是否练熟、是否知道彼此习惯。

- 队友加练会提高目标队友默契。
- 战术会议成功会小幅提高全队队友默契。
- 一起赢下赛事会小幅提高全队队友默契。
- 低信任下输掉赛事会降低全队队友默契。

队伍默契不是独立存储字段，而是由全队队友默契和 `teamTrust` 派生出来。队友默契是主体，队伍信任是发挥环境；极低信任会额外压低队伍默契。

### 协同和队伍身份

阵容协同由玩家特质和队友特质共同决定：

- 有 IGL 且团队存在战术标签，会加成。
- 有 AWPer 且团队存在枪法天赋，会加成。
- 多个 support 标签会加成。
- 玩家是 IGL 且有 support 队友，会加成。
- 多个 ego 或 solo 标签会扣分。

队伍身份系统会推导谁是 caller、star、veteran、rookie、glue 或 problem。身份会影响队内政治、冲突风险、队友离队和社交叙事。

### teamTrust

`teamTrust` 表示队伍关系和更衣室信任。它不再作为独立胜率修正直接叠加，而是参与派生队伍默契：

- 高信任会让已有默契更容易发挥。
- 低信任会压低配合执行。
- 极低信任会让原本练熟的配合在关键局变形。

### 队友离队

系统会为队友生成转会预警和离队计划：

- 先出现匿名流言。
- 再出现具名预警。
- 玩家可提前应对。
- 如果离队发生，会补新人；提前处理会影响新人质量。

这让战队不是静态加成，而是一个会变化的职业环境。

## 赛事系统

赛事是晋级和成就的核心。赛事有报名窗口、门槛、赛程、资格奖励和多阶段 bracket。

### 赛事层级

赛事采用按年份推进的赛季日历，统一使用 C/B/A/S/Major 的竞技层级：

- C 级赛事：新人公开生态，门槛低，奖励少，主要用于积累比赛感和取得 B 级种子资格。
- B 级赛事：分为公开 B 赛和青训 B 赛。公开 B 赛通常需要 `B级种子资格`；青训 B 赛属于战队体系。
- A 级赛事：二线到职业晋级关键。
- S 级公开 / 封闭预选：通往顶级正赛的资格链。
- S 级正赛：职业生态核心赛事。
- Major：最高荣誉目标。

实际会出现的赛事品牌包括 Faceit Rookie Night、Community Open、Platform Ladder Cup、Rookie Circuit、After Hours Cup、Weekend Rookie Clash、Late Season Open、Last Chance Rookie Cup、Academy League、City Masters、Open Cup、Faceit Proving Series、Platform Challenger Cup、ESL Challenger、CCT、BLAST、IEM、PGL、ESL Pro League、Major 等。

赛事可能要求：

- 当前阶段。
- 名气。
- 战队等级。
- 战队积分。
- 个人或战队资格门票。
- 指定报名周。

报名后，比赛通常不会立刻打，而是安排到后续周，给玩家一个准备窗口。当前报名会安排两周后的比赛：报名周创建上下文，下一周可准备，再下一周进入比赛。

### 资格门票

部分赛事会奖励资格门票。资格可能归属：

- 玩家个人。
- 战队。

门票可以让玩家或队伍进入更高层级赛事。某些报名门槛可以通过资格门票破格进入。

资格不会在跨年时统一清空，而是从获得时起滚动有效约 48 周。报名时会消耗一张对应资格；如果已经报名成功，即使资格在赛事进行期间到期，本次赛事也不会被取消。退赛会返还原资格及其原本过期时间。

当前主资格链：

```text
C 级赛事夺冠
  -> B级种子资格
  -> 部分公开 B 级赛事
B 级赛事夺冠
  -> A级公开预选门票
  -> A Open
A Open 晋级决赛
  -> A级正赛资格
  -> A Main
A Main 四强或夺冠
  -> 品牌 S 级预选资格
  -> IEM / BLAST / PGL 等 S 级预选
S 级预选晋级决赛
  -> S 级正赛资格
  -> S Main
S Main 或品牌主线资格
  -> Major 资格链
```

C 级不会直接产出 A 级资格，它的作用是给新人提供更密集的早期赛事和进入 B 级公开赛的铺垫。

### 赛事上下文

报名后会创建 `tournamentContext`，用于控制赛事前后的上下文事件：

- `signup`：报名当周的压力、期待、准备计划。
- `pre-match`：赛前训练、媒体、队伍安排或伤病压力。
- `match`：比赛周，只出比赛事件。
- `post-match`：赛后采访、复盘、舆论、队伍反馈。
- `complete`：上下文结束。

上下文事件有优先级，会根据赛事压力、赛事重要性、队伍状态、伤病、胜负和冠军结果筛选。AI 生成的赛事上下文事件也可以进入同一队列。

### 弃赛

玩家可以弃赛，但会付出代价：

- 压力 +25。
- 名气 -10。
- 二线或职业阶段可能罚款 30K。
- 消耗的合法资格会按规则返还。
- 添加近期弃赛标签。

弃赛是救急按钮，不是无代价撤销。

## 比赛模拟

正式比赛不走普通事件检定，而是独立模拟。

### 有效枪法

比赛先计算玩家的有效枪法，大致由以下因素组成：

- `agility` 和 `experience` 形成枪法基础。
- `feel` 直接提高或降低即时表现。
- 高疲劳削弱表现。
- `tilt` 削弱表现。
- Buff 和部分队伍管理结果提供短期修正。

当前比赛模拟拆成两层：

- 个人表现层：决定 K/D/A、HS% 和 Rating。
- 队伍胜负层：由玩家表现、队友能力、团队协同、队伍默契、队伍信任和对手强度共同决定。

无固定队伍的 C/B 公开赛按临时队参赛处理。

### 赛前预览

玩家报名赛事后，待赛卡片会展示方向性的赛前状态预览，包括：

- 手感。
- 疲劳。
- tilt。
- 心态。
- 队伍信任。
- 团队协同。
- 队伍默契。
- 特别高或特别低的关键队友默契。

它不会暴露完整胜率公式，但会提示哪些因素正在上浮或拖累比赛表现。

### 对手强度和胜率

对手强度由赛事基础难度和 bracket 阶段修正决定。越接近决赛，难度通常越高。

胜率主要由：

- 玩家个人表现、队伍强度和对手强度差。
- 心态带来的稳定性修正。
- 队伍协同、队伍默契、战术统一和 Buff。

胜率会被限制在合理区间，不会 0% 或 100%。

### 个人数据

比赛会生成：

- 比分
- 击杀
- 死亡
- 助攻
- 爆头率
- rating

这些数据由同一套比赛模型生成，而不是互相独立随机。

#### 比分

比赛先根据胜率决定胜负，再根据强弱差生成分差：

- 强势获胜更容易出现较大比分优势。
- 接近五五开的比赛更容易打成接近比分。
- 爆冷局通常比分更紧。

比赛以 `13:x` 或 `x:13` 结算，总回合数由比分决定。

#### K / D / A

个人数据按每回合贡献生成：

```text
kills = round(KPR * totalRounds)
deaths = round(DPR * totalRounds)
assists = round(APR * totalRounds)
```

这样短局、小样本数据不会因为固定下限被抬高。

#### 爆头率

爆头率先由枪法、手感和随机波动得到爆头概率，再结合实际击杀数生成爆头击杀：

```text
headshotKills = round(kills * headshotChance)
HS% = headshotKills / kills
```

所以 `HS%` 和实际击杀数绑定，不再是一个独立飘动的比例。

#### Rating

Rating 使用每回合贡献模型：

```text
rating =
  0.34
  + KPR * 0.98
  - DPR * 0.24
  + APR * 0.18
  + HS% * 0.10
  + 决策修正
  + 胜负修正
  + 分差修正
```

Bo3 / Bo5 系列赛的最终 rating 以单图 rating 平均值为基础，再追加很轻的系列赛胜负修正和横扫修正。因此 `2:0` 会比 `2:1` 略好，但不会夸张拉开。

这些数据会影响：

- 赛后叙事。
- 手感变化。
- tilt 变化。
- 疲劳变化。
- 赛事奖励、积分和资格推进。
- 队伍信任、队友默契和社交反馈。

## 积分榜和世界俱乐部

游戏维护一份战队积分榜。它的作用包括：

- 展示玩家队伍所处位置。
- 校验部分大赛报名门槛。
- 作为赛事生态的动态背景。

玩家队伍赢得赛事会增加积分；其他队伍也会随时间滚动变化。进入更高层级赛事时，战队积分会越来越重要。

世界俱乐部系统会维护相关俱乐部的运行态：

- 近期状态。
- 阵容稳定度。
- 内部化学反应。
- 俱乐部信任。
- 当前需求角色或身份。
- 活跃故事线，例如黑马、重建、化学反应危机、老将下滑、明星爆发。

这些信息会影响申请提示、社交动态、队伍事件和职业世界的背景变化。

## 商店和经济系统

经济系统让职业生涯多了现实约束。钱不是简单分数，而是恢复、训练效率、舆论经营和债务风险的基础。

### 商店类别

商店分为：

- 消耗品：能量饮料、外卖套餐、止痛药。
- 服务：心理咨询、枪法私教、战术复盘、短途旅行、理疗按摩。
- 装备：外设升级、人体工学椅、护腕支撑套。
- 社交：请队友吃饭、粉丝见面会、媒体专访、签约 / 解雇经纪人。

商品可能有：

- 价格。
- 冷却。
- 阶段门槛。
- 名气门槛。
- 正面效果。
- 负面随机事件。
- Buff。
- 标签添加或移除。

### Buff

Buff 是商店和部分系统给玩家留下的短期或长期状态修正。它们不是直接突破成长上限的手段，而是改变后续行动、事件或比赛的结算效率。

Buff 可能影响：

- 指定行动标签的成长倍率。
- 指定属性的成长收益。
- 正向疲劳增量。
- 正向压力增量。
- 比赛胜率。
- 比赛 rating。
- 比赛疲劳 / 压力。
- 队伍化学反应。

Buff 有剩余次数和触发条件，用完后移除。

### 外设

游戏外设升级是特殊装备分支。价格随等级递增，升级不保证成功：

- 好结果：提高或稳定手感上限。
- 坏结果：钱花了但手感上限提升有限，甚至被假货或不适配拖累。

外设影响的是比赛即时状态空间，不是直接增加敏捷。

### 贷款、朋友借款和典当

经济压力可以通过几条路径缓解：

- 银行贷款：青训以后可借，单笔 20K-100K，12 回合后按 10% 利息还款；违约会降低名气并添加转会禁止标签。
- 朋友借款：无息，8 回合还款，金额 10K-30K，要求信用值足够。
- 典当装备：把可典当装备换成周转资金，但失去对应装备收益。

贷款不是免费资源。它可以救急，但会影响后续转会、名气和压力。

### 生活成本

项目包含生活、住房和经济压力相关设计与事件。资金不足会持续影响心态、压力、恢复质量和可用选择。赚钱行动能缓解现金流，但会把疲劳和压力推高。

## AI 叙事和社交动态

AI 启用后，系统可以生成：

- 开场故事。
- 事件叙事润色。
- 流式叙事。
- 商店购买叙事。
- 生涯总结。
- 自由行动判定和二次校验。

- 临时事件。

未启用 AI 时，系统使用模板内容兜底。自由行动和流式叙事这类强依赖 LLM 的能力会返回错误或被前端跳过。

社交动态会混合：

- 玩家近期表现。
- 队伍状态。
- 世界俱乐部故事线。
- 媒体账号和粉丝视角。
- 对手、队友和经纪人相关内容。

高名气会带来更多机会，也会放大失误和舆论压力。

## 生涯目标面板

游戏会根据当前阶段生成职业目标：

- 新人阶段：C/B 级参赛、B 级参赛、C/B 级冠军、青训申请资格。
- 青训阶段：B 级赛事参赛和冠军，争取晋级二线队。
- 二线阶段：A 级赛事参赛和冠军，争取晋级职业队。
- 职业阶段：S 级赛事、Major、名气和传奇结局。

目标面板还会显示未来 12 周内相关赛事机会，以及当前战队风格给出的推进提示。它是玩家判断下一步行动的主要导航。

## 典型策略

- 不要只堆枪法。敏捷能带来击杀，但心态、体能、经验和队伍默契会决定能不能在关键比赛里稳定发挥。
- 低体能角色要谨慎连续训练和赚钱。疲劳会放大压力，并压低比赛表现。
- 高名气不是纯收益。它能打开战队和赛事机会，也会引来媒体事件和社交压力。
- 早期 C/B 级赛事很重要。它们是青训申请、资格门票和职业叙事的起点。
- 有战队后要维护队友默契和 `teamTrust`。强队不是静态 Buff，内部关系会影响比赛和转会。
- 经济短缺时不要只靠贷款。赚钱行动、典当、商店节制和赛事奖金都要一起考虑。
- 报名赛事后要看赛前状态预览。手感、疲劳、tilt、队伍信任和关键队友默契都会改变实际表现。
