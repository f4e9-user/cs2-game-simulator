# CS2 电竞选手人生模拟器：游戏系统说明

这是一款以 CS2 职业生涯为主题的文字冒险 + 数值模拟游戏。它把选手成长、压力疲劳、战队合同、赛事资格、队友阵容、经济压力、名气舆论和 AI 叙事串成一条完整的职业生涯线。

玩家扮演一名想打职业的 CS2 新人，从路人阶段开始，通过训练、天梯、赚钱、休息、申请战队、参加赛事、经营队伍关系和处理随机事件，尝试进入更高等级的战队，并在有限的生涯时间内打出足够高的成就。

---

## 游戏目标

游戏没有单一线性胜利条件，更像一段职业生涯：

- 短期目标：活下来，控制压力和疲劳，保证 AP 和经济不断档。
- 中期目标：提升能力，打出赛事成绩，加入更高等级战队。
- 长期目标：进入职业阶段，冲击 S 级赛事、Major、高名气和传奇结局。

玩家可能以多种方式收束生涯：

- 成为高名气职业明星。
- 赢下 Major 或重要赛事。
- 作为自由人打出草根传奇。
- 长期效力同一队成为忠诚老将。
- 因压力、伤病、经济或普通退役结束职业道路。

---

## 核心循环

一局游戏的主循环：

```text
抽特质 / 分配属性
      ↓
进入每周回合
      ↓
行动阶段：训练、天梯、恢复、赚钱、购物、报名、战队和队伍管理
      ↓
结束行动阶段，根据最新状态抽取本回合事件
      ↓
事件阶段：固定选项，或在 AI 启用时输入自由行动
      ↓
结算属性、压力、疲劳、手感、名气、资金、战队关系和赛事状态
      ↓
推进周数，刷新事件，检查晋级、薪资、贷款、资格和结局
```

每回合的关键资源是 AP。玩家不能无限训练，也不能无限恢复。高收益行动通常带来疲劳、压力或经济成本；恢复行动会牺牲手感或成长速度。

当前实现把回合拆成两个阶段：

- `action`：行动阶段。玩家可以做日常行动、购物、贷款、典当、申请 / 离队、报名 / 弃赛、队伍管理等操作。
- `event`：事件阶段。系统会根据本回合行动后的最新状态选出事件，玩家只能处理事件选项或 AI 自由行动。

`currentEvent` 只在事件阶段存在；行动阶段不会提前固定下一事件。

### 长事件流程

普通事件之外，游戏支持同回合 `Event Sequence`：

- 战队面试会连续走完多个提问后再结算。
- 家人危机、队内冲突会以多步流程展开。
- Bo3 / Bo5 赛事会按地图拆成同回合系列赛。
- 赛事上下文会围绕报名、赛前、赛后承接，但比赛周只出比赛事件。

事件卡会显示当前流程进度，历史记录也会把同一流程的记录分组显示。

## 开局系统

### 特质

开局会随机抽取 3 个特质，玩家可以重抽 1 次。特质同时影响：

- 属性底线或修正。
- 标签和叙事身份。
- 行动检定、事件门槛、团队协同和部分风险。

典型特质方向：

- 枪法天才：提高敏捷，带来 `aimer` / `mechanical` 标签。
- 战术大脑：提高智力，带来 `igl` / `tactical` 标签。
- 冰冷心脏：提高心态，擅长抗压。
- 训练狂：成长潜力强，但可能更难停下来恢复。
- 玻璃腕：枪法强，但伤病风险高。
- 自负、急性子、社恐、沉迷型等负面或混合特质，会在事件和团队系统里持续产生影响。

特质不是简单的正负数值。同一个行动在不同角色身上会呈现不同风险，例如 `grinder` 更适合训练，`solo` 更适合天梯，但可能伤害团队协同。

### 开局身份

本版本开局身份固定为「无标签新人」。玩家不是从一组选定背景中开局，而是通过特质、属性分配和后续选择逐步塑造职业身份。

开局重点是：

- 选手名。
- 随机 3 个特质。
- 在 4 个可分配竞技属性上分配 10 点；`experience` 不参与开局分配，特质可以给它提供初始修正。

## 生涯阶段

正式阶段链路：

```text
rookie -> youth -> second -> pro -> retired
```

对应含义：

- `rookie`：路人新人，还没有真正进入体系。
- `youth`：青训，开始接触俱乐部体系。
- `second`：二线队，具备半职业或次级赛事资格。
- `pro`：职业队，进入高等级赛事生态。
- `retired`：退役。

阶段不是只靠经验自动升级，而是和战队、赛事成绩和晋级叙事事件绑定。

### rookie -> youth

新人进入青训的核心路径是申请青训档战队。现在这条路径不再要求先满足 C / B 级赛事硬门槛，而是改成结果分层：

- 表现足够强时，直接给通过结果。
- 表现一般时，给试训结果。
- 表现不足时，给拒绝结果。

评分会参考赛事履历、特质、名气、背景、地区匹配、压力和疲劳。申请会消耗 AP，并进入等待回应链路；青训回信会直接给出结果，不再走旧版“先履历门槛、再天赋面试”的双门槛流程。

### youth -> second

青训晋级二线队依赖 B 级赛事门槛：

- B 级赛事参赛不少于 3 场。
- B 级赛事夺冠不少于 1 场。

满足条件后，系统会注入晋级叙事事件，而不是直接静默升级。晋级成功代表签下更高层级合同，会同步换到真实二线俱乐部，并重新生成队友阵容、月薪和队伍信任。

### second -> pro

二线队晋级职业队依赖 A 级赛事门槛：

- A 级赛事参赛不少于 3 场。
- A 级赛事夺冠不少于 1 场。

满足条件后同样通过晋级签约事件推进。晋级成功会换到真实职业俱乐部。

`pro` 是当前正式竞技阶段终点。更高的明星、传奇、老将是目标和结局评价，而不是新的阶段。

## 属性系统

玩家有 4 个可分配竞技属性，`experience` 作为履历属性不吃开局点数，另有一个经济属性 `money`。

| 属性 | 含义 | 主要影响 |
| --- | --- | --- |
| `intelligence` 智力 | 战术理解、复盘、决策 | 系统训练、陪玩指导、比赛 rating、部分事件选择 |
| `agility` 敏捷 | 枪法、反应、定位 | 天梯、比赛胜率、击杀、爆头率 |
| `experience` 经验 | 比赛经验和稳定输出 | 枪法基础、决策基础、长期表现 |
| `mentality` 心态 | 抗压和情绪稳定 | 压力增量、比赛稳定性、恢复行动 |
| `constitution` 体能 | 身体耐受和恢复能力 | 疲劳增量、伤病风险、连续作战 |
| `money` 资金 | 经济资源 | 商店、贷款、工资、奖金、罚款和生活压力 |

开局可在特质底线之上分配 10 点，但只能分配到以下 4 个属性：

- `intelligence`
- `agility`
- `mentality`
- `constitution`

`experience` 不参与开局分配，初始值主要由特质修正和后续生涯推进决定。

`money` 不参与开局分配。它通过赛事奖金、工资、赚钱行动、贷款、朋友借款、典当、商店消费和罚款变化。

竞技属性通常在 `0-20` 区间，资金上限更高。

### 成长衰减

成长不是线性堆数值。属性越高，继续成长越慢：

| 当前属性 | 成长倍率 |
| --- | --- |
| `< 5` | `1.0` |
| `< 10` | `0.7` |
| `< 15` | `0.4` |
| `>= 15` | `0.15` |

生涯总成长有上限，当前核心成长预算为 30，只作用于 4 个可成长竞技属性；`experience` 和 `money` 不计入成长预算。这意味着玩家必须选择成长方向，而不是全属性拉满。

## 状态系统

除核心属性外，游戏还维护一组高频波动状态。

### AP

`actionPoints` 是每回合行动资源。日常行动、申请战队、队伍管理等会消耗 AP。AP 决定玩家每周能做多少事。

### 压力 stress

压力范围是 `0-100`。压力过高不是立刻结束，而是进入挂满计数：

- 压力达到上限后累计 `stressMaxRounds`。
- 连续撑满到阈值后触发 `stress_breakdown` 结局。
- 心态越高，每回合被动降压越明显。
- 疲劳超过 70 时，正向压力增量会被放大。

正向压力增量的核心逻辑：

```text
最终压力增量 =
  基础压力增量
  × 心态倍率
  × 特质压力倍率
  × Buff 压力倍率
  × 高疲劳压力放大
```

当前心态倍率：

| 心态 | 正向压力倍率 |
| --- | --- |
| `>= 16` | `0.30` |
| `>= 13` | `0.55` |
| `>= 9` | `0.85` |
| `>= 5` | `1.25` |
| `< 5` | `1.60` |

疲劳达到 `70` 后，正向压力增量还会额外放大到 `1.4` 倍。降压效果不会因为高心态被削弱。

### 疲劳 fatigue

疲劳范围是 `0-100`。训练、天梯、比赛、赚钱行动会增加疲劳；休息、度假、商店服务会降低疲劳。

正向疲劳增量的核心逻辑：

```text
最终疲劳增量 =
  原始疲劳增量
  × 体能倍率
  × 特质疲劳倍率
  × Buff 疲劳倍率
```

当前体能倍率：

| 体能 | 正向疲劳倍率 |
| --- | --- |
| `>= 15` | `0.30` |
| `>= 11` | `0.55` |
| `>= 7` | `0.85` |
| `>= 4` | `1.35` |
| `< 4` | `1.60` |

为了避免高体能角色完全无成本行动，正向增量有最低值：日常行动最低 `5` 点疲劳，随机事件最低 `2` 点疲劳，正式比赛最低 `8` 点疲劳。

### 手感 feel

手感影响比赛即时发挥：

- 正手感提高有效枪法。
- 负手感降低比赛表现。
- 休息和断网会恢复身体，但可能让手感下降。
- 外设升级可以提高或改变手感上限。

默认手感范围是 `-3 ~ +3`，外设系统可以把上限推高。

### tilt

`tilt` 是心态波动，范围 `0-3`。失败、连败、爆冷输球会增加 tilt；逆转胜或恢复类内容可能降低 tilt。比赛中 tilt 会直接削弱有效枪法。

### 名气 fame

名气影响：

- 战队申请门槛。
- 高等级俱乐部门槛。
- 媒体、粉丝和社交事件。
- 部分赛事机会。
- 结局评价。

名气不是纯正收益。更高曝光也会带来媒体事件、压力和舆论风险。

## 日常行动

日常行动是玩家主动塑造角色的主要手段。当前行动包括：

| 行动 | AP | 主要收益 | 主要代价 |
| --- | ---: | --- | --- |
| 打天梯 | 30 | 敏捷成长、手感 | 疲劳、压力、tilt 风险 |
| 系统训练 | 30 | 智力成长 | 疲劳、压力 |
| 休息一天 | 30 | 降疲劳、降压力 | 手感下降 |
| 度假断网 | 50 | 大幅恢复 | 手感明显下降，占用大量 AP |
| 健身锻炼 | 30 | 体能成长 | 疲劳 |
| 冥想静心 | 15 | 降疲劳、降压力 | 恢复较轻，不提供成长 |
| 心理训练 | 30 | 心态成长 | 疲劳、压力 |
| 代练接单 | 35 | 赚钱，偏敏捷检定 | 高疲劳、高压力 |
| 陪玩指导 | 30 | 赚钱，偏智力检定 | 疲劳、耐心消耗 |
| 网吧打工 | 35 | 赚钱，偏体能检定 | 高疲劳 |

行动会走检定。检定通常由主属性、可选副属性、特质加成、特质惩罚和难度共同决定。

### 行动 Combo

日常行动支持同一回合内的行动连锁。玩家先执行一个行动，可能开启本回合 combo 标记；后续按正确顺序执行匹配行动时，会消费标记并获得额外收益。

当前 Combo 路线：

| 连锁 | 额外收益方向 |
| --- | --- |
| 系统训练 -> 打天梯 | 敏捷成长提高，tilt 风险降低 |
| 打天梯 -> 系统训练 | 智力成长提高，压力增长降低 |
| 冥想静心 -> 打天梯 / 心理训练 | 压力和 tilt 风险降低 |
| 健身锻炼 -> 系统训练 / 打天梯 | 疲劳增长降低 |
| 度假断网 -> 打天梯 | 找回手感，疲劳增长降低 |
| 代练接单 / 陪玩指导 / 网吧打工 -> 冥想静心 / 休息一天 | 额外恢复疲劳和压力 |

Combo 只在本回合有效，触发后消耗，回合结束会清空。它不同于商店 Buff：Buff 是持续收益，Combo 是行动顺序带来的一次性收益。

## 事件系统

事件系统负责制造职业生涯的不确定性。事件会根据玩家当前状态动态抽取。

事件来源包括：

- 训练
- 天梯
- 战队
- 试训
- 赛事
- 媒体
- 生活
- 救助
- 博彩
- 作弊
- 休养
- 压力
- 对手
- 直播 / 社交
- 每日链路
- 皮肤
- 经纪人
- 赛事上下文

事件筛选会考虑：

- 当前阶段。
- 玩家标签。
- 禁止标签。
- 最近事件去重。
- 压力、疲劳、名气和经济状态。
- 是否报名赛事。
- 是否处于面试或申请链路。
- 是否强制休养。
- 是否签约经纪人。

某些状态会强插事件。例如强制休养时优先进入休养事件池，报名赛事后会出现赛前或赛后上下文，申请战队后会进入回应 / 面试链路。

### 自由行动

开启 AI 后，玩家可以在事件阶段输入自定义行动。系统会让 LLM 评判行动质量，并映射成检定加成：

- `poor`：负面或低质量行动。
- `ok`：普通行动。
- `good`：较好行动。
- `excellent`：非常贴合情境的行动。

随后系统会二次校验这个判定是否合理。校验失败时会降级为普通选择，避免 LLM 给出过度奖励。自由行动最多 50 个字，只在事件阶段可用。

## 战队系统

战队是生涯推进的核心系统之一。它不仅提供身份，还影响赛事资格、薪资、队友、协同、积分榜和社交动态。

### 俱乐部等级

当前俱乐部分为：

- `youth`：青训队。
- `semi-pro`：半职业 / 二线队。
- `pro`：职业队。
- `top`：顶级队。

不同等级有不同阶段和名气门槛。顶级队通常要求职业阶段和较高名气。

### 申请和 Offer

玩家可以申请俱乐部。申请会：

- 消耗 AP。
- 检查阶段、名气、贷款违约禁转等门槛。
- 激活该俱乐部运行态。
- 生成等待回应。
- 后续通过事件进入面试或拒绝链路。

面试成功后会生成 Offer。接受 Offer 后：

- 进入对应最低阶段。
- 获得月薪。
- 生成队友阵容。
- 初始化队伍信任。
- 加入战队积分榜生态。

赛事晋级签约也复用同一套入队结算，但不会按违约跳槽处理；原队伍资格会清空，新队伍会重新建立阵容和薪资。

### 跳槽和合同争议

如果玩家已有战队又接受新 Offer，会触发违约式跳槽：

- 名气下降。
- 压力上升。
- 添加合同争议标签。
- 新队初始信任更低。

这让「骑驴找马」有收益，也有舆论和团队代价。

### 薪资和奖金分成

战队提供月薪，薪资按周期发放。更高等级队伍薪资更高，但赛事奖金分成给玩家的比例更低：

| 战队等级 | 玩家奖金分成 |
| --- | --- |
| youth | 85% |
| semi-pro | 70% |
| pro | 60% |
| top | 50% |

顶级队给稳定薪资和赛事资格，但选手不再拿走全部奖金。

## 阵容和队友

加入战队后会生成队友阵容。队友有：

- 角色：`IGL`、`AWPer`、`Entry`、`Support`、`Lurker`
- 个性：严格、支持、明星、苦练、戏剧型
- 数值：敏捷、智力、心态、经验
- 特质标签
- 成长空间
- 队友默契
- 可见队伍身份

队友不是纯展示文本，会影响比赛团队加成。

### 队伍管理

加入战队后，战队面板会开放队伍管理动作。这些动作消耗 AP，属于本回合行动的一部分。

- 队友加练：指定一名队友加练，按队友角色判定主要成长属性。成功会让该队友对应属性小幅成长，并提高默契。
- 战术会议：尝试统一默认战术。成功提高 `teamTrust`，并获得一次性赛事情境增益「战术统一」。
- 安抚更衣室：只在 `locker-tension` 或低 `teamTrust` 时可用。成功提高队伍信任并移除更衣室紧张。
- 挽留核心队友：在队友离队压力出现时尝试保住核心。
- 队伍训练重点：选择队伍训练方向，改变短期队伍培养和状态。

队伍管理不能在赛事实际比赛周进行，但报名后的备赛周仍可以安排。当前版本会让队伍管理影响队友属性、队友默契、队伍信任、疲劳、压力和短期比赛稳定性。

### 队友默契和队伍默契

每名队友有自己的队友默契。它表示玩家和这名队友是否练熟、是否知道彼此习惯。

- 队友加练会提高目标队友默契。
- 战术会议成功会小幅提高全队队友默契。
- 一起赢下赛事会小幅提高全队队友默契。
- 低信任下输掉赛事会降低全队队友默契。

队伍默契不是独立存储字段，而是由全队队友默契和 `teamTrust` 派生出来。队友默契是主体，队伍信任是发挥环境；极低信任会额外压低队伍默契。

### 协同和队伍身份

阵容协同由玩家特质和队友特质共同决定：

- 有 IGL 且团队存在战术标签，会加成。
- 有 AWPer 且团队存在枪法天赋，会加成。
- 多个 support 标签会加成。
- 玩家是 IGL 且有 support 队友，会加成。
- 多个 ego 或 solo 标签会扣分。

队伍身份系统会推导谁是 caller、star、veteran、rookie、glue 或 problem。身份会影响队内政治、冲突风险、队友离队和社交叙事。

### teamTrust

`teamTrust` 表示队伍关系和更衣室信任。它不再作为独立胜率修正直接叠加，而是参与派生队伍默契：

- 高信任会让已有默契更容易发挥。
- 低信任会压低配合执行。
- 极低信任会让原本练熟的配合在关键局变形。

### 队友离队

系统会为队友生成转会预警和离队计划：

- 先出现匿名流言。
- 再出现具名预警。
- 玩家可提前应对。
- 如果离队发生，会补新人；提前处理会影响新人质量。

这让战队不是静态加成，而是一个会变化的职业环境。

## 赛事系统

赛事是晋级和成就的核心。赛事有报名窗口、门槛、赛程、资格奖励和多阶段 bracket。

### 赛事层级

赛事采用按年份推进的赛季日历，统一使用 C / B / A / S / Major 的竞技层级：

- C 级赛事：新人公开生态，门槛低，奖励少，主要用于积累比赛感和取得 B 级种子资格。
- B 级赛事：分为公开 B 赛和青训 B 赛。公开 B 赛通常需要 `B级种子资格`；青训 B 赛属于战队体系。
- A 级赛事：二线到职业晋级关键。
- S 级公开 / 封闭预选：通往顶级正赛的资格链。
- Major：顶级目标，通常依赖更高阶段和完整资格链。

### 报名和资格链

赛事报名不只是一次点击，它会检查：

- 当前阶段。
- 战队等级。
- 名气。
- 种子资格 / VRS 门槛。
- 是否处于报名窗口。
- 是否满足本赛季资格链条。

部分赛事会给出资格门票或通向更高赛事的链路。玩家可以提前看到自己是从哪里进来、能通往哪里去。

### 比赛模拟

比赛模拟把个人表现和队伍胜负分开：

- 个人表现层：K / D / A、HS%、rating、关键回合表现。
- 队伍胜负层：比分、晋级、奖金、资格推进。

这样即使个人数据不差，也可能因为队伍协同、压力或赛事上下文而输掉比赛。

### 赛事上下文

报名后、赛前、赛后会插入赛事上下文事件。比赛周只会出比赛相关事件，避免普通事件打断系列赛流程。

## 经济系统

经济系统不只是余额显示，它是职业决策的一部分。

### 收入和支出

资金来源包括：

- 赛事奖金。
- 月薪。
- 赚钱行动。
- 朋友借款。
- 经纪人相关收益。

资金支出包括：

- 商店消费。
- 贷款还款。
- 生活开销。
- 罚款。
- 违约和合同争议代价。

### 商店

商店提供装备、 Buff 和恢复类服务。它可以提升短期表现，也可能改变手感上限或恢复节奏。

### 贷款、典当和借款

这些是草根选手常用的短期周转工具：

- 贷款：先解决眼前问题，再面对还款压力。
- 朋友借款：缓冲风险，但会埋下关系成本。
- 典当：快速换钱，但会丢掉资产或状态。

经济系统的目标是让玩家在训练、赛事和生存之间做真实取舍，而不是单纯刷数值。

## AI 和叙事

AI 是叙事层增强，不是游戏规则本身。

当前支持：

- 开场故事。
- 事件叙事润色和流式叙事。
- 商店购买叙事。
- 生涯总结。
- 自由行动判定和二次校验。
- 社交动态。
- 临时事件生成和 AI 事件缓存。

AI 生成事件会先经过结构化校验，再进入缓存。即使 AI 不可用，游戏也能继续跑，只是叙事会退回模板文本。

## 界面与调试

### 页面

- `/`：新局创建，包含选手名、特质抽取、重抽和属性分配。
- `/game/:sessionId`：主游戏界面，包含 HUD、目标、事件、行动、商店、贷款、战队、赛事、社交动态、历史和结局面板。
- `/debug`：本地调试入口。
- `/debug/sessions`：session 列表。
- `/debug/sessions/:sessionId`：单个 session 调试视图。

### 调试能力

调试页可查看：

- session 状态。
- LLM 日志。
- AI 状态。
- AI 事件缓存。
- 事件流程状态。

## 接口概览

业务路由挂载在 `/api` 下。写操作通常需要创建 session 时返回的 `apiToken`，通过 `Authorization: Bearer <apiToken>` 传入。

- `GET /api/health`
- `GET /api/game/:sessionId`

更完整的接口清单请看后端路由和源码注释。

## 开发提醒

- 行动阶段和事件阶段有严格路由限制。
- 长事件流程进行中时，报名、退赛、离队、日常行动等操作会被拦截。
- 资金变化优先走统一经济模块。
- 修改类型时同步后端、前端和 `shared/types.ts`。
- 新增赛事、战队或队伍功能时，要同时考虑门槛、资格链、队友默契、`teamTrust` 和比赛模拟。
