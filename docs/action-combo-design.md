# 日常行动 Combo 设计

这份文档记录日常行动 combo 的设计边界和版本规划。

Combo 不是商店 Buff，也不是跨多周计划。它是同一回合内的行动顺序奖励：玩家先执行某个行动，获得一个只在本回合有效的连锁标记；后续按正确顺序执行匹配行动时，消费该标记并获得额外收益。

---

## 设计目标

- 让玩家从“点收益最高的按钮”转向“安排本回合行动顺序”。
- 让日常行动之间产生因果，而不是互相独立。
- 保持当前 `AP = 100` 的回合结构，不引入跨周计划负担。
- 不替代现有商店 Buff。商店 Buff 仍是持续倍率，combo 是本回合顺序奖励。
- 不突破成长上限，combo 只能提高效率或修正状态风险。

---

## 当前 AP 前提

当前日常行动已经按轻重重新分档：

| 类型 | 行动 | AP |
| --- | --- | ---: |
| 轻行动 | 冥想静心 | 15 |
| 标准成长/恢复 | 打天梯、系统训练、休息一天、健身锻炼、心理训练、陪玩指导 | 30 |
| 重赚钱 | 代练接单、网吧打工 | 35 |
| 大恢复 | 度假断网 | 50 |

这个结构适合做同回合 combo：

- `30 + 30 + 15 = 75`：标准组合后还能留少量空间。
- `50 + 30 + 15 = 95`：大恢复后接一个主行动，基本占满本回合。
- `35 + 30 + 15 = 80`：赚钱、恢复、调整之间有取舍。

---

## 核心规则

### 1. Combo 只在当前回合有效

行动产生的 combo 标记进入 `roundCombos`，回合结束时清空。

```ts
interface RoundCombo {
  id: string;
  label: string;
  sourceActionId: string;
  remainingUses: number;
}
```

### 2. 行动可以开启或消费 combo

```ts
interface ComboOpen {
  id: string;
  label: string;
  requireSuccess?: boolean;
}

interface ComboConsume {
  id: string;
  label: string;
  effects: {
    growthMultiplier?: number;
    growthKey?: StatKey;
    fatigueGainMultiplier?: number;
    stressGainMultiplier?: number;
    feelDelta?: number;
    tiltDelta?: number;
    checkBonus?: number;
  };
}
```

行动定义可以扩展：

```ts
interface ActionDef {
  comboOpens?: ComboOpen[];
  comboConsumes?: ComboConsume[];
}
```

### 3. 结算顺序

```text
1. 玩家选择行动。
2. 系统查找本行动可消费的 roundCombos。
3. 把 combo 效果加入本次检定、成长、疲劳、压力、手感或 tilt 结算。
4. 消费已触发的 combo 标记。
5. 如果本行动成功，并配置 comboOpens，则添加新的 roundCombo。
6. 回合结束时清空未消费的 roundCombos。
```

### 4. 强度边界

- `growthMultiplier` 建议 `1.05 - 1.10`。
- `fatigueGainMultiplier` 建议 `0.90 - 0.95`。
- `stressGainMultiplier` 建议 `0.85 - 0.95`。
- `checkBonus` 常规为 `+1`，强 combo 才给 `+2`。
- `feelDelta` 常规为 `+0.5` 或 `+1`。
- `tiltDelta` 常规为 `-1`。当前 tilt 是整数状态，不使用半点修正。

Combo 奖励应该小于商店 Buff，但更精准、更依赖顺序。

## Combo v1

v1 已实现。它只使用当前已经存在的日常行动，不新增队伍管理行动，不接赛事专属准备动作。

目标是先验证玩家是否会因为 combo 改变同一回合的行动顺序。

### 1. 系统训练 -> 打天梯

先理解，再实战验证。

```text
系统训练成功后开启：结构化思路
本回合后续打天梯消费
```

效果建议：

- 敏捷成长倍率 `+8%`。
- 失败时 tilt 增量 `-1`。

价值：

- 让训练后的实战更有意义。
- 支持“先练思路，再打天梯”的路线。

### 2. 打天梯 -> 系统训练

先暴露问题，再复盘训练。

```text
打天梯后开启：实战问题
本回合后续系统训练消费
```

效果建议：

- 智力成长倍率 `+8%`。
- 压力增量倍率 `0.90`。

价值：

- 和“系统训练 -> 打天梯”形成方向差异。
- 前者偏敏捷成长，后者偏智力成长和复盘。

### 3. 冥想静心 -> 打天梯 / 心理训练

轻行动作为高压行动前置。

```text
冥想静心成功后开启：心流准备
本回合后续打天梯或心理训练消费
```

效果建议：

- 压力增量倍率 `0.85`。
- tilt 增量 `-1`。

价值：

- 冥想不只是低 AP 恢复按钮，也可以成为高压行动前的准备。

### 4. 健身锻炼 -> 系统训练 / 打天梯

先激活身体，再进入竞技训练。

```text
健身锻炼成功后开启：身体激活
本回合后续系统训练或打天梯消费
```

效果建议：

- 疲劳增量倍率 `0.90`。

价值：

- 让体能行动和竞技行动产生直接联系。
- 高体能路线不只是长期疲劳倍率，也有本回合操作价值。

### 5. 度假断网 -> 打天梯

大恢复后找回手感。

```text
度假断网后开启：身体清空
本回合后续打天梯消费
```

效果建议：

- 手感 `+1`。
- 疲劳增量倍率 `0.90`。

价值：

- `50 AP + 30 AP = 80 AP`，这是一条明确的回合路线。
- 度假不只是清状态，也可以接一次找手感行动。

### 6. 代练接单 / 网吧打工 -> 冥想静心 / 休息一天

赚钱后的自我修复。

```text
代练接单或网吧打工后开启：透支感
本回合后续冥想静心或休息一天消费
```

效果建议：

- 额外疲劳 `-5`。
- 额外压力 `-5`。

价值：

- 赚钱行动仍然高消耗，但玩家可以安排后续恢复来处理代价。
- 让经济路线不只是“缺钱就点赚钱”。

## Combo v2

v2 放在后续实现，因为它需要新增行动或接入更多系统。

### 1. 队伍管理 combo

需要先新增主动队伍行动：

- 战术会议：提高 `teamTrust` 或短期比赛协同，消耗 AP。
- 队友加练：提高队友默契或特定角色协同，增加疲劳。
- 安抚更衣室：降低 `locker-tension` 或冲突风险。

可设计 combo：

```text
请队友吃饭 -> 战术会议
```

效果：

- 战术会议检定 `+2`。
- `teamTrust` 额外 `+5`。

```text
战术会议 -> 比赛
```

效果：

- 比赛压力增量倍率 `0.90`。
- 临时团队修正 `+1`。

### 2. 赛事准备 combo

需要明确赛事准备行动或赛前窗口。

可设计 combo：

```text
系统训练 -> 赛前准备事件
心理训练 -> 关键比赛
战术会议 -> 正式比赛
```

效果方向：

- 降低比赛压力增长。
- 降低 tilt 风险。
- 小幅提高比赛稳定性。
- 不直接大幅提高胜率。

### 3. 商店服务和行动 combo

当前商店已有 Buff，不建议把商店 Buff 改成 combo。v2 可以只做少量“购买后同回合行动”的额外提示。

可设计 combo：

```text
枪法私教 -> 打天梯
战术复盘 -> 系统训练
心理咨询 -> 心理训练 / 比赛
```

这类 combo 要和已有 Buff 区分：

- Buff 负责持续收益。
- Combo 只给一次小额即时收益或风险修正。

### 4. 多段 combo

v1 只做两段 combo。v2 可以少量引入三段路线：

```text
冥想静心 -> 系统训练 -> 打天梯
```

效果：

- 第一段降低训练压力。
- 第二段提高打天梯成长或降低 tilt。

多段 combo 必须谨慎，避免形成唯一最优固定流程。

## UI 需求

### 行动按钮提示

当玩家已有可被消费的 combo 时，对应行动按钮显示：

```text
可触发连锁：结构化思路
敏捷成长效率提高，tilt 风险降低
```

### 行动结果提示

触发 combo 后在结果中显示：

```text
触发连锁：结构化思路
```

### 本回合连锁状态

HUD 或行动面板可显示：

```text
结构化思路：打天梯可触发
心流准备：打天梯 / 心理训练可触发
```

## 当前实现状态

Combo v1 已完成：

- 后端玩家状态增加 `roundCombos`。
- 新建角色初始化 `roundCombos`。
- 回合推进时清空未消费 combo。
- 行动定义支持 `comboOpens` 和 `comboConsumes`。
- 行动结算会消费本回合已有 combo，并接入成长、疲劳、压力、手感和 tilt 结算。
- 前端行动按钮会展示当前可触发 combo。
- 行动结果会展示已触发和新开启的 combo。

后续进入 v2：

1. 新增队伍管理行动，例如战术会议、队友加练、安抚更衣室。
2. 接入队伍管理 combo。
3. 设计赛事准备 combo。
4. 评估商店服务和同回合行动的一次性 combo。
5. 谨慎加入少量三段 combo。
