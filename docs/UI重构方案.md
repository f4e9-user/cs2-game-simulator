# 电竞生涯模拟器 · 前端重构方案（实现规格）

> 用途：本文档是给实现方（人或 AI）照着改前端用的规格说明。所有颜色给出十六进制值，每个区块标注用什么颜色、什么 emoji，并附颜色速查表与 emoji 速查表。
> 适用范围：保留"一屏尽量看全"的三栏布局，重点是**重新分配每栏的内容**，并统一一套语义化的颜色 / 字体 / 组件规范。

---

## 0. 设计目标（先理解，再动手）

1. **三栏不变，但每栏职责必须明确**：左＝这回合**做什么**，中＝**正在发生什么**，右＝**你是谁**。
2. **解决两个具体痛点**：
   - 右栏过挤——原因是把"无限滚动的动态流"和"定高的档案卡"塞进了同一根窄列。
   - 中栏过空——原因是事件页只有一张决策卡。
   - **解法**：把动态流（社区动态 / 我的动态 / 赛事提醒）从右栏搬到中栏；右栏只保留定高、不滚动的"角色档案"。
3. **颜色语义化、强调色稀缺**：橙色（品牌色）只允许出现在"唯一主行动"和"当前激活的标签"上，其它任何地方禁止使用橙色。
4. **数字一律等宽对齐**：所有数值用等宽字体 + `tabular-nums`，保证跨行对齐。
5. **「职业助手」不是一个模块，而是四类内容的集合，必须按类型拆开归位**：未来 12 周赛程 → 左栏赛事日历；本周建议 → 左栏顶部提示条；下一目标 → 右栏目标进度卡；当前风险 → 右栏风险预警卡。同理「战队信息」要拆成"本队"与"转会市场"两个子标签。

## 1. 整体布局

顶栏常驻；下面三栏。左右栏定宽，中栏自适应。左右栏在桌面端 `position: sticky`，各自内部滚动，保证"一屏看全"。

```
┌ 顶栏：常驻状态（身份 | 能力 | 资源 | 排名） 全宽 sticky ──────────────────┐
├──────────────┬────────────────────────────────────┬──────────────────────┤
│ 左栏 · 操作    │ 中栏 · 焦点 + 动态流                 │ 右栏 · 个人档案        │
│ 宽 ~288px     │ 自适应（最宽）                       │ 宽 ~348px             │
│              │                                    │                      │
│ 💡 本周建议   │ ┌ 当前事件（决策卡，占满宽）──────┐ │ 生涯战绩              │
│              │ │ ◆ 教练组问阵容看法              │ │  参赛/夺冠/ABCS      │
│ 赛事日历      │ │ [选项A][选项B][选项C]           │ │                      │
│  · 资格       │ └────────────────────────────────┘ │ 特质与标签            │
│  · 12周赛程   │ ┌ 焦点区 60% ──┐┌ 动态流 40% ────┐ │  · 性格/成就/风险/冷却│
│  · 报名       │ │ ⚠ 赛事提醒   ││ 社区动态(滚动)  │ │                      │
│ 日常行动 AP   │ │ 赛程时间线   ││ HLTV / 队友…   │ │ 下一目标（进度）      │
│  · 训练/恢复  │ │ (含"我的动态")││ 对手 / 明星…   │ │ 风险预警（离队+连败） │
│  · 赚钱       │ └──────────────┘└────────────────┘ │ 薪资发放              │
│ [推进回合 →] │  中栏 = 四个标签页：事件/商店/战队/排行  │                      │
└──────────────┴────────────────────────────────────┴──────────────────────┘
```

**栏内容分配总表**

| 栏 | 装什么 | 不装什么 |
|---|---|---|
| 顶栏 | 身份、4 项能力、5 项资源状态、排名、星级 | — |
| 左栏（操作） | **本周建议提示条**、赛事日历（含**未来 12 周赛程**）+ 报名、AP 行动（训练/恢复/赚钱）、推进回合按钮 | 任何动态流、任何档案数据 |
| 中栏（四个标签页） | 事件页（决策卡 + 焦点 + 动态流）、商店页（含**租房**）、战队页（**本队 + 转会市场**）、排行榜页 | 个人档案数据 |
| 右栏（档案） | 生涯战绩、特质标签、**下一目标进度**、**风险预警（离队 + 连败合并）**、薪资发放 | 任何滚动的流；右栏所有卡片必须**定高、一屏装下** |

> **「职业助手」面板被解散**：原面板里的"未来 12 周赛程 / 本周建议 / 下一目标 / 当前风险"是四种不同内容，按上表分别归入左栏与右栏，不再作为一个独立模块。若想保留"助手"的叙事语气，集中放到左栏"本周建议"提示条里即可。

> **关于切换 tab 时动态流消失**：动态流属于"事件/主页"内容。当用户切到 商店 / 战队 / 排行榜 时，中栏被这些页面占用，社区动态不再显示——这是预期行为。做决策时真正要盯的是右栏档案卡（钱、风险、目标、特质），它一直在。

## 2. 设计系统

### 2.1 颜色 Token（直接粘贴到 `:root`）

```css
:root{
  /* 背景层次：用明度分层代替到处描边 */
  --bg:#0b0e15;          /* 页面底色 */
  --surface:#121724;     /* 卡片底 */
  --surface-2:#1a2030;   /* 卡内嵌块 / hover 态 */
  --row:#10141e;         /* 列表行底 */
  --border:#242c3d;      /* 主边框 */
  --border-soft:#1b2331; /* 弱边框 / 分隔线 */

  /* 文字 */
  --text:#e8ecf4;        /* 主文字 */
  --muted:#8b95a8;       /* 次要文字 / 描述 */
  --faint:#59627a;       /* 弱文字 / 占位 / 单位 */

  /* 语义色（关键：每种颜色只对应一种含义） */
  --brand:#ff5a1f;       /* 橙：主行动 + 当前激活标签，仅此用途 */
  --ability:#56b6f2;     /* 冷青：能力值（枪法/决策/稳定性/续航） */
  --gold:#e3b341;        /* 金：资金 / 价格 / 成就 / 星级 */
  --green:#56c271;       /* 绿：正向 / 已拥有 / 队友 / 夺冠 / 增益 */
  --red:#e5575c;         /* 红：危险 / 对手 / 风险 / 买不起 / 减益 */
  --purple:#c678dd;      /* 紫：名气 / 明星 / 特殊 */
  --amber:#d99a3a;       /* 琥珀：压力 / 中等警示 */
  --slate:#5c6b82;       /* 石板蓝灰：中性徽章 / 媒体 */
}
```

**强制规则**

- 橙色 `--brand` **只能**用于：① 当前激活的标签下划线/底色；② 整屏唯一的主行动按钮（如"推进回合""出发""报名"）。**价格、标签、普通按钮一律不准用橙色。**
- 价格永远用金色 `--gold`；买不起时价格变红 `--red`。
- 能力值统一冷青 `--ability`，**不要用红色**（红色＝警告，会误导）。
- 背景靠 `--bg < --row < --surface < --surface-2` 四级明度区分层次，少描边。

### 2.2 字体

```css
--mono:'JetBrains Mono', ui-monospace, monospace;     /* 所有数字 / 数据 */
--disp:'Rajdhani', 'Noto Sans SC', sans-serif;        /* 标题 / 标签 / 按钮 */
--body:'Noto Sans SC', system-ui, sans-serif;         /* 正文中文 */
```

- 所有数值加 `font-variant-numeric: tabular-nums;` 实现等宽对齐。
- 标题/标签用 `--disp`，可加 `letter-spacing: .03em` 增强运动感，英文/大写标签用 `text-transform: uppercase`。
- **国内访问建议自托管字体**；若不想引入英文字体，中文可统一退回"思源黑体 / Noto Sans SC"本地字体。

### 2.3 间距与圆角

- 卡片圆角 `10px`，列表行 / 嵌块圆角 `7–8px`，徽章 `4–5px`。
- 卡片内边距 `13–15px`；列表行内边距 `12–14px`。
- 区块之间间距 `14–16px`。

## 3. 顶部状态栏（常驻）

分成四组，组间用 `1px solid var(--border-soft)` 竖线分隔。

| 分组 | 内容 | 颜色标注 |
|---|---|---|
| 身份 | 名字 `123`（`--disp` 700 26px）、`Y5 · W6`（`--mono` `--faint`）、标签 `职业` / `DRG +65K/月` | `职业` 用绿色描边胶囊（`--green`）；`DRG` 胶囊用冷青描边（`--ability`），其中 `+65K` 用金色 `--gold` |
| 能力 | 枪法 68 / 决策 47 / 稳定性 23 / 续航 27 | 数值 `--mono` 700 `--text`；下方 4px 进度条填充用 `--ability`，轨道 `#222a3a`；显示 `值/100` |
| 资源 | 手感 +4/4、疲劳 0、压力 20、资金 139K、名气 87 | 手感→`--green`；疲劳→`--muted`（0 为好）；压力→`--amber`；资金→`--gold`；名气→`--purple`。全部 `--mono` |
| 排名 | `RANK #4` `137 pts` 做成独立描边小方块；右侧 ★★ 星级 | `#4` 用橙 `--brand`；`137 pts` 用 `--muted`；星 ★ 用金 `--gold` |

**Emoji**：顶栏不用 emoji。星级用字符 `★`（金色），不要用 emoji 的 ⭐。

## 4. 左栏 · 操作

### 4.1 本周建议提示条（职业阶段，来自原「职业助手」）

放在左栏最顶部，一条带左侧色条的提示盒（不是卡片，更轻），用来承接"助手"的指导语气。

- 标题行：`规划顶级赛事窗口` + 右侧优先级胶囊 `高`（高=`--amber`，中=`--ability`，低=`--faint`）。
- 正文（`--muted`）：如"职业阶段的核心收益来自 S 级赛事、Major、名气和冠军记录。让训练、恢复和报名围绕高价值赛事展开。"
- 代价行（`--amber` 或 `--muted`，带 `代价：` 前缀）："顶级赛事失败代价更高，需要保留状态余量。"
- 左侧色条 `--ability`（建议=信息，不是危险），前缀 emoji 💡。

### 4.2 赛事日历卡（含未来 12 周赛程）

- 卡头标题"赛事日历"，可带一个 `?` 帮助圆点（`--faint` 描边）。
- 资格行：底色 `--surface-2`，文字 `--muted`，其中资格名（如 `BLAST 封闭预选门票 ×2`）用金色 `--gold` + `--mono`。
- **未来 12 周晋级赛程**（核心内容，原"职业助手"里的赛程搬到这里）：一个按周排列的列表，每行结构如下——

  `周次` + `等级徽章` + `赛事名` + `右侧状态/报名按钮`

  | 字段 | 样式 |
  |---|---|
  | 周次（第 6 周…） | `--mono` `--faint` |
  | 等级徽章 | Major → 金 `--gold`（最高荣誉）；S 级 → 紫 `--purple`；B/C → 冷青/石板。预选 vs 正赛 再加一个小 `--mono` 灰字标注（`预选`/`正赛`） |
  | 赛事名 | `--text` 600 |
  | 可报名 | 橙色 `报名` 按钮（`--brand`，这是该行主行动） |
  | 无法报名 | 置灰文字 `无法报名`（`--faint`），不显示按钮；可加灰字原因 |

  示例数据（按此渲染）：
  - 第 6 周 · `S级·预选` · IEM London 2030 Open Qualifier · **无法报名**
  - 第 11 周 · `S级·正赛` · IEM Singapore 2030 · **可报名**
  - 第 12 周 · `S级·正赛` · BLAST Bounty Season 9 · **可报名**
  - 第 15 周 · `Major` · IEM Melbourne Major 2030 · **无法报名**
  - 第 18 周 · `S级·预选` · BLAST Open Atlanta Season 9 Closed Qualifier · **可报名**

### 4.3 日常行动卡

- 顶部 AP 预算：`100 / 100 AP`，剩余数字用橙 `--brand`；下面一条 5px 预算条，填充 `--brand`，轨道 `#222a3a`。
- 行动**按类别分三组**，组标题用 `--disp` `--faint` 小号大写：

  | 组 | 行动 | AP 成本 chip 颜色 |
  |---|---|---|
  | 训练成长 | 打天梯 30、系统训练 30、健身锻炼 30、心理训练 30 | 中性：`--muted` 文字 + `--surface-2` 底 + `--border-soft` 边 |
  | 恢复调整 | 休息一天 30、冥想静心 15、度假断网 50 | 中性（同上） |
  | 赚钱 | 代练接单 35、陪玩指导 30、网吧打工 35 | 绿色：文字 `--green` + 绿色淡底，表示"进账" |

- 行动行：左侧名称（600）+ 描述（`--muted` 小号），右侧 AP 成本 chip。hover 时行底变 `--surface-2`。
- **成本 chip 不要用橙色 / 红色**，避免和主行动、危险冲突；买不起某行动时该 chip 才变红 `--red`。

### 4.4 推进回合按钮（重要）

- 左栏底部放一个**整屏唯一的主行动按钮**：`推进到下一回合 →`，橙色实底 `--brand`，深色文字 `#1a0d04`，全宽，字号大。
- 这是整个回合循环的收尾动作，必须最显眼。

**Emoji**：左栏不用 emoji，保持操作区干净。

## 5. 中栏 · 四个标签页（事件 / 商店 / 战队 / 排行榜）

中栏顶部是四个标签：`事件`（默认）`商店` `战队` `排行榜`。当前激活标签用橙底 `--brand` + 深字；其余用 `--muted`，hover 变 `--surface-2`。下面 5.1–5.2 是默认的「事件页」，5.3–5.5 是其余三页。

### 5.1 当前事件（决策卡，占满中栏宽度，置顶）

- 背景用轻微渐变 `linear-gradient(180deg,#161c2a,#121724)` + `--border` 边框，比普通卡更突出。
- 顶部一个事件类型标签 + 事件编号：

  | 事件类型 | 标签颜色 | Emoji |
  |---|---|---|
  | 队内 | 冷青 `--ability` 淡底 | ⬡ |
  | 赛事 | 金 `--gold` 淡底 | 🏆 |
  | 媒体 | 石板 `--slate` 淡底 | 📰 |
  | 转会 | 紫 `--purple` 淡底 | 🔁 |

  编号（如 `R197`）用 `--mono` `--faint`。
- 标题 `--disp` 700 24px；正文 `#c5ccda` 14px 行高 1.7，宽度限制约 62 字符。
- 选项区：每个选项是一行（底 `--surface-2`，边 `--border`，hover 边框变橙 `--brand`）。左侧 `→ 选项文字`（箭头用橙 `--brand`），右侧后果预览用 `--mono`：增益用 `--green`（如"默契 +"），减益用 `--red`（如"默契 −"）。

### 5.2 焦点区 + 动态流（决策卡下方，左右分栏 60% / 40%）

**左 60% · 焦点区**：放赛事提醒 + 赛程时间线（"我的动态"并入这条时间线，因为它本质就是你的决策/赛果记录）。

- 时间线竖线 `--border`；节点圆点按结果着色：胜＝`--green`、负＝`--red`、中性/进行中＝`--faint`。
- 每条：回合编号（`--mono` `--faint`）+ 标题（600）+ 结果胶囊 + 描述（`--muted`）。
  - 结果胶囊：夺冠/胜→绿底绿字 `--green`；出局/负→红底红字 `--red`。
- 赛事提醒（如"BLAST 预选窗口开启"）放在时间线顶部，用 ⚠ 前缀（琥珀 `--amber`）或 🏆（金，正面赛事）。

**右 40% · 社区动态（内部滚动）**：

- 每条 feed：头像名 + handle（`--mono` `--faint`）+ 右侧角色徽章 + 正文（`#c0c8d6`）。
- **角色徽章配色（全局统一，描边胶囊）**：

  | 角色 | 颜色 | 备注 |
  |---|---|---|
  | 媒体 | `--slate` #5c6b82 | HLTV / IW Watch 等 |
  | 队友 | `--green` #56c271 | 王Rain / DRG_Cipher4 |
  | 俱乐部 | `--ability` #56b6f2 | 龙腾电竞官方 |
  | 对手 | `--red` #e5575c | SpectreBurst / Reverb |
  | 明星选手 | `--gold` #e3b341 | NiKo / s1mple_legacy |
  | 圈内人士 | `--amber` #d99a3a | 解说小刘 等 |

- **正文里的 emoji 属于游戏数据**（如队友发的 😅🔥👕），保留原样，不要由 UI 统一添加。
- 这一列必须 `overflow-y: auto` 内部滚动，**不要把整页撑高**（这是解决"右栏被撑乱"的核心）。

### 5.3 商店页

商店按"区块（section）"分组，每个 section 一个色条 + 标题 + 副标题。普通商品用 §7.1 的列表行三态。区块顺序建议：**居住 → 消耗品 → 服务 → 装备 → 社交**。

#### 5.3.1 居住 / 租房（档位单选，重点新增）

租房不是买断式商品，而是**五选一的居住档位**，渲染方式要和普通商品区分开。

- 区块头：`居住` + 副标题 `基础生活费 1K/周 · 本地城市`，色条 `--gold`，前缀 🏠。
- 每个档位是一张卡，从低到高排列，卡内信息：

  | 字段 | 样式 |
  |---|---|
  | 档位名 | `--text` 600 |
  | 描述 | `--muted` |
  | 周支出 | 金 `--gold` + `--mono`，后缀 `/周`（这是**周期性**支出） |
  | 疲劳 -X / 压力 -X | **绿色 `--green`**（这是对负面属性的削减＝增益，用恢复色） |
  | 搬家成本 | 一次性，金额 `--mono`；做成按钮 `搬家 6K` |

- **当前档位**：卡片高亮（橙边 `--brand` 淡底），右上角徽章 `居住中`（`--brand` 或 `--green`），按钮替换为禁用态 `当前档位`。
- 其它档位：按钮 `搬家 {金额}`（次行动描边样式，避免一屏多个橙按钮）；买不起 → 按钮禁用 + 金额变红 `--red`。
- 数据（按此渲染，当前档位＝宿舍/合租）：

  | 档位 | 周支出 | 疲劳 | 压力 | 搬家 | 备注 |
  |---|---|---|---|---|---|
  | 宿舍 / 合租 | 1K/周 | -0 | -0 | — | 当前居住中 |
  | 普通租房 | 3K/周 | -1 | -1 | 6K | — |
  | 标准公寓 | 6K/周 | -2 | -2 | 18K | 中期现金流选择 |
  | 高端公寓 | 10K/周 | -3 | -3 | 40K | — |
  | 自有房产 | 2K/周 | -3 | -2 | 120K | **长期投资**：一次性成本极高、周期开销低，可加金色"长期"小标 |

#### 5.3.2 消耗品 / 服务 / 装备 / 社交

## 10. 给实现方的注意事项

1. 所有颜色集中在 `:root` 变量，换肤只改这一处；组件里一律引用变量，不写死 hex。
2. 数字一律 `--mono` + `tabular-nums`，确保跨行对齐。
3. 能力满值此处按 `/100` 假设，请按游戏实际上限调整进度条 `width` 与显示分母。
4. 优先保证桌面"一屏看全"：左右栏 `position: sticky` 各自内部滚动；中栏动态流列 `overflow-y:auto` 内部滚动，**不得把整页撑高**。
5. 响应式：窄屏（如 <1180px）可降级为单列堆叠，但本项目以桌面"看全"为主，不必为窄屏牺牲桌面密度。
6. 最重要的一条原则：**橙色是稀缺资源**——通篇检查，橙色只出现在唯一主行动和当前激活标签上，发现别处用橙立即改成对应语义色。
