# 居住与早期经济压力设计

状态：草案。

## 背景

当前经济系统已经包含商店、工资、奖金、贷款、典当、罚款和赚钱行动，但新人阶段如果没有稳定支出，`money` 往往只在中后期才真正进入决策。

这会让经济系统更像“可选工具”，而不是职业生涯早期的核心压力来源。

## 设计目标

- 让 `money` 从开局就变成必须管理的资源。
- 让新人阶段出现稳定但不致命的现金压力。
- 让住宿、恢复、训练、打工、贷款形成早期决策闭环。
- 让后期购房成为长期投资，而不是纯装饰资产。

## 系统拆分

### 1. 固定生活开销

每周自动扣除固定开销，包含：

- 住宿费
- 生活费
- 通勤费

要求：

- 金额要稳定存在。
- 不能高到直接卡死新人。
- 目标是让玩家每周都要看余额，而不是只在买商店时才看。

### 2. 住宿层级

住宿不只是背景设定，而是可升级的经济状态。

建议分层：

- 宿舍 / 合租
- 普通租房
- 高级公寓
- 购房

### 3. 后期房产

后期房产不能只做“省钱”，最好同时提供：

- 周期开销降低
- 轻微恢复加成
- 生活类事件解锁
- 身份感变化

## 早期经济决策

早期典型取舍应当是：

```text
本周是继续训练，还是去打工凑枪法私教的钱？
是贷款买恢复服务，还是硬撑去打比赛？
是先把住宿升级到不那么伤状态的房型，还是把钱留给下周的训练/赛事？
```

## 价值

- 让 money 成为策略资源，而不是单纯余额。
- 强化草根选手早期压力。
- 让商店和贷款系统更早参与核心循环。
- 让“住哪儿”成为职业阶段的一部分。

## 其他金钱压力来源

除了住宿，经济压力还可以由这些来源共同构成：

### 1. 固定生存费

- 吃饭
- 交通
- 网费
- 训练场通勤

适合早期稳定扣费，让每周现金流都有压力。

### 2. 训练相关消费

- 枪法私教
- 战术复盘
- 心理咨询
- 理疗按摩

这类支出可以直接和成长、恢复、压力管理绑定，让玩家在“练”和“花钱保状态”之间取舍。

### 3. 赛事成本

- 报名费
- 差旅费
- 住宿费
- 签证费

适合中后期，把“打比赛”做成有成本的行为。

### 4. 装备维护

- 外设升级
- 维修
- 替换

这类成本可以做成偶发但高影响的支出项。

### 5. 战队相关支出

- 队内聚餐
- 团建
- 训练室分摊
- 违约金

可以强化“加入战队不是纯收益”。

### 6. 社交和品牌成本

- 请客
- 见面会
- 经纪人分成
- 媒体公关

名气越高，这部分支出越像职业的一部分。

### 7. 健康与恢复成本

- 理疗
- 药物
- 休养
- 搬到更好的环境

这类成本适合把“撑状态”变成要花钱的决策。

### 8. 风险性支出

- 贷款利息
- 违约罚金
- 弃赛罚款
- 违规成本

这类支出负责把错误选择变成真实代价。

## 落地原则

- 新人阶段默认有固定生活开销。
- 住宿升级不和短期恢复道具混用。
- 住宿升级只提供小幅但持续的收益，避免压过赛事、训练和贷款。
- 后期房产作为资产型选择，降低周期开销并提供少量长期增益。
